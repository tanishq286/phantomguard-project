# PhantomGuard Project

An agentic, AI-driven application guard system designed to monitor runtime security and analyze potential vulnerabilities within modern JavaScript ecosystems.

## Features
- **Automated Dependency Auditing**: Deep scan local packages for known architectural CVEs.
- **Runtime Guarding**: Sandboxing features to detect malicious system calls.
- **WSL Native Optimization**: Optimized specifically to balance environment performance inside Linux subsystems.

## Installation

Install the guard system via npm:

```bash
npm install
```

## Usage

To initialize a localized guard environment:

```bash
npm start
```
